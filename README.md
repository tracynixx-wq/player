# Player — test MVP

Минимальная Flutter-основа для Android и iOS.

## Что проверяется сейчас

- запуск приложения;
- выбор локального аудиофайла;
- воспроизведение, пауза и перемотка;
- распознавание ссылки на плейлист Spotify и извлечение ID.

## Что пока не подключено

- загрузка треков Spotify через Web API;
- авторизация Spotify;
- поиск совпадений в музыкальном каталоге;
- Supabase и синхронизация;
- фоновые уведомления и управление с экрана блокировки.

Spotify-ссылка на этом этапе только проверяется локально. Для чтения метаданных плейлиста потребуется настройка приложения в Spotify Developer Dashboard и реализация разрешённого API-доступа.

## Сборка Android

GitHub Actions запускается при push в main/master или вручную через Actions. Debug APK публикуется как artifact.
